# Design Patterns

## Creational Patterns (Object banane ke liye)

- Singleton
- Factory Method
- Abstract Factory
- Builder
- Prototype

## Structural Patterns (Classes/objects ko organize karne ke liye)

- Adapter
- Bridge
- Composite
- Decorator
- Facade
- Flyweight
- Proxy

## Behavioral Patterns (Objects ke beech interaction ke liye)

- Chain of Responsibility
- Command
- Interpreter
- Iterator
- Mediator
- Memento
- Observer
- State
- Strategy
- Template Method
- Visitor

---

## Short Explanation

### Creational

Ye patterns object creation ko control karte hain taaki system flexible aur reusable ho.

### Structural

Ye patterns classes aur objects ko aise arrange karte hain ki system simple aur efficient rahe.

### Behavioral

Ye patterns define karte hain ki objects ek dusre ke saath kaise communicate karte hain.
