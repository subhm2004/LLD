# Images / Diagrams for Singleton Notes

`L10 Singleton_Design_Pattern/C++ Code` ke andar abhi koi image file (`.png`, `.jpg`, `.jpeg`, `.svg`, etc.) detect nahi hui.

## Recommended setup

Agar tum diagrams/screenshots add karna chaho, yeh structure follow karo:

```text
C++ Code/
  notes/
    images/
      simple-singleton-flow.png
      thread-safe-locking.png
      double-checked-locking.png
```

Phir markdown me aise reference karo:

```md
![Simple Singleton Flow](./images/simple-singleton-flow.png)
```

Chaaho to next step me main khud `notes/images/` folder bana ke placeholder markdown links bhi set kar sakta hoon.
