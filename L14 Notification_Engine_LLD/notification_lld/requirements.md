# Requirements

## Functional
- Send notification through Email, SMS, and Popup channels.
- Register recipients and dispatch notification messages.
- Decorate notification payloads with timestamp and signature.
- Support multiple runtime notification strategies.

## Non-Functional
- Extensible architecture with minimal code changes for new channels.
- Modular header-first folder structure for LLD consistency.
- Easy to plug into client code via `NotificationSystem`.
