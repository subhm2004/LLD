# Problem Statement: Tinder-Like Dating App LLD

Design an in-memory dating platform where users can discover nearby profiles, swipe, match, and chat.

The system should support:

1. User onboarding with profile metadata and location.
2. Nearby profile discovery.
3. Swipe left / right actions.
4. Super like action.
5. Match creation on mutual likes.
6. Chat between matched users.
7. Daily swipe limit.
8. Unmatch and block flows.

The design should be modular so advanced ranking and recommendation systems can be added later.
