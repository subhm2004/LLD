# Problem Statement: Uber-Like Ride Hailing System

Design an in-memory ride hailing system where riders can request rides and the system assigns the nearest available driver.

The system should support:

1. Rider and driver registration.
2. Driver location tracking.
3. Ride request with pickup/drop.
4. Driver assignment through matching logic.
5. Ride state transitions and fare calculation.

The design should be modular and extensible for future production-like enhancements.
