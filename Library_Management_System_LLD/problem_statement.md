# Problem Statement: Library Management System

Design a low-level in-memory Library Management System that can be used by a librarian to manage books and by members to borrow and return books.

The system should support:

1. Adding books to catalog.
2. Registering members.
3. Searching books by title.
4. Issuing a book to a member.
5. Returning a book and calculating late fine.

The design must be modular and extensible so that future features like reservation, notifications, and persistence can be added.
